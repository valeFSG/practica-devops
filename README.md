# MiProyectoDevops

##  Descripción

Este proyecto tiene como objetivo aplicar los fundamentos de Git y GitHub, implementando un flujo de trabajo colaborativo junto con automatización mediante GitHub Actions.

Se incluye la validación automática de archivos Markdown para asegurar buenas prácticas de documentación.

---

## Objetivos

- Utilizar control de versiones con Git
- Trabajar con ramas (main y develop)
- Crear y gestionar Pull Requests
- Automatizar procesos con GitHub Actions
- Aplicar buenas prácticas en Markdown
